# PostQode Community

A collection of runnable, community-contributed content for [PostQode](https://www.postqode.ai) - real code you can point PostQode at, and real code that extends what PostQode can do.

Looking for best-practice guides, rules, or workflow prompts instead? Those live in [`awesome-postqode`](https://github.com/postqode/awesome-postqode). The short version:

| Repo                             | What it's for                                            |
|----------------------------------|----------------------------------------------------------|
| `awesome-postqode`               | How PostQode *should behave* - rules, workflows, prompts |
| `postqode-community` (this repo) | Actual code - apps to test, integrations to run          |

The two repos are kept separate on purpose: different clone weight, different review bar (reading markdown vs. building and running code), different contribution model. See [CONTRIBUTING.md](CONTRIBUTING.md) for details.

## What's in here

### `samples/apps/`

Target applications. Point PostQode at these to extend, refactor, debug, document, and generate or write unit, API, or web tests.

### `samples/integrations/`

Reference implementations that extend what PostQode can do - MCP servers, auth clients, and similar. Read these to learn how to build your own.

See [CONTRIBUTING.md](CONTRIBUTING.md) if you'd like to add your own.
